# laurent-site

Site vitrine de Laurent Garrigues, jardinier paysagiste à Béziers.
Pages statiques (HTML, CSS, JS), hébergées avec GitHub Pages.

- `index.html` : page d'accueil
- `blog.html` et `article-*.html` : le blog
- `img/` : photos des chantiers
- Formulaire de devis : Web3Forms (clé à coller dans `index.html`, constante `WEB3FORMS_KEY`)
